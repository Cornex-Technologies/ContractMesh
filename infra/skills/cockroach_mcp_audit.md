# CockroachDB Managed MCP Audit Guide & Runbook

## Overview
CodeClaim provisions a cluster-scoped, read-only audit user (`mcp_audit_agent`) and dedicated relational views (`contract_drift_audit`, `contract_publication_audit`) that enable AI coding assistants (Claude Code, Cursor, VS Code) to query the entire distributed contract mesh and multi-agent reconciliation lifecycle via the **CockroachDB Managed Model Context Protocol (MCP)**.

---

## 2. Setting Up CockroachDB MCP in Your IDE

### In Claude Code / Cursor (`~/.cursor/mcp.json` or `.claude/settings.json`):

```json
{
  "mcpServers": {
    "cockroach-codeclaim-audit": {
      "command": "npx",
      "args": [
        "-y",
        "@cockroachdb/mcp-server",
        "--connection-string",
        "postgresql://mcp_audit_agent:<MCP_AUDIT_PASSWORD>@codeclaim-prod.cockroachlabs.cloud:26257/codeclaim_db?sslmode=verify-full"
      ]
    }
  }
}
```

## 3. Sample MCP Natural Language Audit Prompts

### Prompt 1: Audit Breaking Schema Changes & Interventions
> **User Prompt:** *"Show all contract changes in Billing-Service that caused downstream interventions."*

**Automated SQL Generated by MCP:**
```sql
SELECT 
    drift_id,
    source_service,
    target_service,
    old_contract_revision,
    new_contract_revision,
    breaking_diff,
    status,
    created_at,
    reconciled_at
FROM contract_drift_audit
WHERE source_service = 'billing-service'
ORDER BY created_at DESC
LIMIT 10;
```

---

### Prompt 2: Trace Immutable Publication & Audit Lineage
> **User Prompt:** *"Verify the publication history and schema diffs recorded for Billing-Service."*

**Automated SQL Generated by MCP:**
```sql
SELECT 
    history_id,
    event_type,
    source_service,
    target_service,
    summary,
    schema_diff,
    actor,
    created_at
FROM contract_publication_audit
WHERE source_service = 'billing-service'
ORDER BY created_at DESC
LIMIT 10;
```

---

### Prompt 3: Semantic Discovery Across Candidate Contracts
> **User Prompt:** *"Find all registered microservice contracts that accept Stripe payment tokens or process charges."*

**Automated SQL Generated by MCP:**
```sql
SELECT 
    r.revision_number,
    c.service_name,
    c.endpoint_path,
    r.semantic_summary,
    (r.summary_embedding <=> '[... 1536-dim query embedding ...]'::VECTOR(1536)) AS cosine_distance
FROM service_contract_revisions r
JOIN service_contracts c ON c.contract_id = r.contract_id
ORDER BY cosine_distance ASC
LIMIT 5;
```

## 4. Security & Least-Privilege Guarantees

1. **Read-Only Privilege**: `mcp_audit_agent` is granted strictly `SELECT` permissions on curated audit views and vector tables.
2. **Immutability Enforcement**: `REVOKE INSERT, UPDATE, DELETE, TRUNCATE, DROP, ALTER` is strictly enforced. The MCP agent can never modify database state or tamper with execution receipts.
3. **No Direct Execution**: The MCP agent inspects audit data and assists developers; all code generation and cutover gates remain isolated within sandboxed worktrees.
